# WanderWay - Travel Agency Website

WanderWay is a responsive travel agency website designed to help users explore travel destinations, tour packages, view a gallery, and make booking inquiries.

## Features

- Home section
- Popular Destinations
- Tour Packages
- Travel Gallery
- Booking section
- Responsive design
- Smooth navigation
- Explore Packages button

## Technologies Used

- HTML5
- CSS3
- Bootstrap

## Website Sections

### Home
Introduction to WanderWay and travel services.

### Destinations
Users can explore different travel destinations.

### Packages
Different tour packages with prices and details.

### Gallery
A collection of travel images.

### Booking
Users can submit their booking information.
